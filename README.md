# PING-PONG — 圆形砖块挑战

竖屏弹球打砖块。球从下方挡板发出，只有对准圆形竞技场底部的缺口才能钻进砖区，清空场内全部 3379 块砖即过关。共 6 关，缺口逐级收窄，内部挡条逐级加长。

## 玩法

用浏览器打开 `web/index.html`，点 START 开局。拖动指针或按 `←` / `→`（`A` / `D`）左右移动挡板。

- **进球**：竞技场外壁是实心的，打偏的球会撞外壁或门柱弹回下方腔室；只有对准底部缺口向上的球能进场。缺口两侧是可见的金色门柱。
- **绕过内挡条**：缺口上方横着一条金属挡条，四面都会反弹。球无法从中间穿过，必须绕到挡条左右任一端，才能进到上方砖区；下落时也会被挡条顶面弹回。
- **打砖**：球撞到砖块后沿最浅重叠轴反弹，逐块啃出空洞，而不是直线穿透。碎片继承被击碎砖块的颜色。
- **掉球**：球落到挡板下方或飞出屏幕顶部就损失一颗，`ATTEMPT` 加一。掉球不失败、不重开；场上球全部消失后才补发一颗，并清空当前道具效果。
- **角度与速度**：挡板接球点越靠边，出球角度越斜；本关砖块清得越多，球速越快，最高提升 25%。
- **道具**：砖块破碎时约 2.2% 概率掉落徽章，被挡板接住即生效。
  - `W` 加宽：挡板由 89 px 变 160 px，持续 5 秒。
  - `S` 减速：球速降到 55%，持续 5 秒。
  - `×3` 三倍球：场上每颗球分裂成三颗，上限 2400 颗。
- **HUD**：`CLEARED` 已清除砖数 / 总数、`BALLS` 场上存活球数、`ATTEMPT` 掉球次数、`HITS` 本关挡板击球次数、右下角道具剩余时间。
- **过关**：砖块清空后出现 `STAGE CLEAR` 卡片，显示本关击球数；球群和物理仍在运行。点画布或按 `R` 进入下一关。第 6 关显示 `ALL CLEAR`，再按一次从第一关重新开始。

## 关卡设计

六关共用同一张 3379 块砖的圆形砖阵，每关重新生成。难度由两个量控制：底部缺口宽度、内挡条初始长度。缺口越窄越难进球，挡条越长越难绕进砖区，两者同步收紧。

| 关卡 | 缺口宽度 | 挡条初始长度 | 设计意图 |
| :---: | :---: | :---: | --- |
| 1 | 96 px | 69 px | 教学关。宽缺口容易进球，短挡条容易绕行；本关独有溅射爆炸，每次击砖额外清除半径 22 px 内的所有砖，开局推进快。 |
| 2 | 54 px | 94 px | 入口明显收窄，取消溅射，改为逐块清除，开始考验瞄准。 |
| 3 | 27 px | 120 px | 基准难度。缺口只剩两颗球宽，命中率成为主要瓶颈。 |
| 4 | 23 px | 145 px | 门柱几乎贴住球，挡条两端与外壁的通道变窄，须靠反弹角调整路径。 |
| 5 | 20 px | 159 px | 允许进球的角度极小，多球与减速道具的价值上升。 |
| 6 | 17 px | 171 px | 终关。缺口只比一颗球略宽，挡条最长，绕行路径最远。 |

**动态挡条**：球每次从缺口进入竞技场后，第一次击碎砖块会让挡条总长增加 8 px（左右各 4 px）；同一次进入内的后续击砖不再增长，掉出缺口再重新进入才再次触发。单关累计上限 300 px，换关时重置为该关初始长度。这让"进场"和"留在场内"形成拉扯：挡条越长，下一次从缺口绕进砖区越难，但已经进到上方的球越不容易从底部缺口逃走，清砖效率反而更高。

**关卡节奏**：每关砖阵重新铺满、球速回到基准、击球数与挡条增长清零，所以难度曲线只由关卡参数决定，不跨关累积。关内则相反：砖越掉越多，球越快，挡条越长，同时 `×3` 带来的球群爆发是压缩后段耗时的唯一手段。六关打完循环回第一关。
